# BizIntel Agent

BizIntel Agent is an AI-powered automated business intelligence and research report generator. It combines Hybrid Search (BM25 + Semantic + Reranking), Agentic Workflows, and Natural Language Inference (NLI) to minimize hallucinations and cite solid evidence.

## Getting Started

### 1. Installation

Requires Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

### 2. Configuration

Create a `.env` file in the root directory:

```env
OPENAI_API_KEY=sk-...
```

### 3. Usage

You can use the standalone CLI or the Streamlit web interface:

**Web Interface**
```bash
streamlit run app/streamlit_app.py
```

**CLI**
```bash
python run.py "Give me a deep dive on Stripe"
python run.py "Compare Stripe and Adyen" --mode competitive
```

## Features
- **Data Ingestion**: Intelligent chunking of company reports and texts.
- **Hybrid Retrieval**: BM25 keyword matching fused with BGE Dense Retrieval and MS-MARCO Cross-Encoder re-ranking.
- **Claim Verification**: Automatically detects claims generated by the LLM and runs DeBERTa NLI inference against source chunks to provide confidence scores.
- **Agent Workflow**: Fully restartable execution nodes capable of automated planning and synthesis.

## Data Sandbox
The `data/company_packs` directory contains sample research data for testing (Stripe, Notion, Databricks). Run `python -m retrieval.ingest --all` and `python -m retrieval.build_index --all` to process new manual additions.
